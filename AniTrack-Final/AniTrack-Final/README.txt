====================================
  AniTrack - Anime & TV Tracker
====================================

HOW TO RUN - SIRF 2 STEPS:

STEP 1: Node.js check karo
  - Command Prompt mein type karo: node --version
  - Version dikhe = ready!
  - Nahi dikhe = https://nodejs.org (LTS version download karo)

STEP 2: START_APP.bat double-click karo
  - Pehli baar 3-5 minute wait karo
  - Browser automatically khulega

DEMO LOGIN:
  Email    : demo@anitrack.com
  Password : demo123

FOLDERS:
  backend/   = Node.js server (port 3001)
  frontend/  = React web app (port 5173)

STOP KARNA HO:
  STOP_APP.bat double-click karo

PROBLEMS?
  - "path not found" = ZIP extract karo (Right-click > Extract All)
  - Browser nahi khula = http://localhost:5173 manually open karo
  - Port busy = STOP_APP.bat chalao phir START_APP.bat
